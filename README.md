守望先锋 · 自定义房间分队工具

一个给自定义房间 / 内战用的分队小工具：把名单丢进去，一键随机分队。段位均衡、胜率权重、Ban 位投票、战绩记录都做在里面了。

非官方工具，与暴雪娱乐无关。守望先锋及相关名称为暴雪娱乐的商标。

系统要求：Windows 10 / 11（64 位）。Windows 11 自带 WebView2 运行时；Windows 10 若缺失，安装版会自动装上，免安装版可能需要手动装一次 WebView2 运行时。

功能

- 三种录入方式：手动逐行填写、截图 OCR 识别（支持多张累加、Ctrl+V 直接粘贴）、文本导入（1.xxx 2.xxx 横排竖排都认）
- 两种分队方式：随机分配 / 段位均衡。均衡用穷举找出所有最优解再随机挑一个，同一批人不会永远分到同一队
- 胜率权重（ELO）：按历史胜率微调实力分，胜率低的优先拿到强队友，权重可调
- 地图与模式：地图随机是「抽三张点一张」，最近抽过的图权重自动降低，避免连续重复
- Ban 位：每人投 3 个英雄（权重 3 / 2 / 1），双方撞车时升级为全局第 5 Ban；支持群投票模板和群消息文本导入
- 战绩记录：按「份」管理历史战绩，逐局记录阵容、Ban 位与胜负，可勾选哪几份参与 ELO 计算
- 导出分享：分队图可保存或直接复制到剪贴板；对局记录能一键拼成一张长图发群里

关于自动更新

从 v0.7.1 开始支持自动更新：启动后会静默检查新版本，发现更新时弹窗提示，点一下就自动下载、替换并重启。

不需要卸载重装，战绩和配置都不会丢——数据是独立存放的，跟程序文件无关。

也可以在「设置 → 软件更新」里手动点「检查更新」。

数据存放位置

- 战绩：%APPDATA%\OWTeamGenerator\ow-stats.json
- 设置：%APPDATA%\OWTeamGenerator\ow-settings.json

战绩的默认位置可以在「设置」里改到其他盘，换目录时会自动把已有战绩复制过去。

换电脑时，把这两个文件复制到新机器同一位置就能接着用。

常见问题

打开后白屏 / 提示缺少 WebView2？
先确认系统是 Windows 10 或更新版本。Windows 10 需要单独安装 WebView2 运行时，装完重启软件即可。

杀毒软件报毒？
单文件 exe 偶尔会误报，加入白名单即可。这个程序不会上传任何数据，唯一的联网行为是检查更新（访问 GitHub）。

截图识别不准？
尽量截游戏内的原始画面，别用手机拍屏幕；识别前可以在预览里框选范围内的人物列表区域，准确率会高很多。

更新后想回滚？
到 Releases 下载旧版本的免安装版，直接覆盖即可，战绩不受影响。
